## How it works

Each clue is a definition, and teams name the construction word. It’s built for technical English, vocational and building-trade groups.

## Categories

- **Tools**: hammer, saw, screwdriver, spirit level, clamp
- **Materials**: brick, cement, rebar, mortar, plasterboard
- **Safety**: hard hat, hi-vis vest, steel toe-cap boots, harness, risk assessment
- **Structure**: foundations, roof, lintel, load-bearing wall, rafter
- **Equipment**: scaffolding, cement mixer, crane, excavator, forklift

## Classroom tips

- Ask learners to describe when they use each tool or item on site
- Turn the answers into a site safety briefing role-play
- Useful for apprentices, engineers and site managers
