Set the clock to

Short hand: hours
Long hand: minutes

The long hand moves five minutes at a time.

How to play

Read the time in words. Use the buttons to move the short hand (hours) and the long hand (minutes), then press Check.

  • If the answer is wrong, the clock shows the right time so you can see the difference.
  • There are ten times in each game.
  • Start with o’clock and half past, then add quarters when the class is ready.
